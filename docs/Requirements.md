# Requirements

## System Requirements
- Python 3.12+
- 16GB+ RAM (Recommended for running local LLMs + Vector DB)
- Optional: Dedicated GPU (NVIDIA/CUDA or Apple Silicon) for accelerated LLM inference and transcription.

## Software Requirements
- **Ollama**: Must be installed and running locally to serve the LLM.
- **Git**: For version control.

See `requirements.txt` for specific Python package dependencies.
