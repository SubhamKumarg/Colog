# Development Roadmap

This document outlines the 20-phase roadmap for Colog.

- [x] **Phase 1: Project Setup** - Base structure, Git initialization, Documentation.
- [x] **Phase 2: Configuration** - Environment variables and config module.
- [x] **Phase 3: PDF Parsing** - PyMuPDF text extraction.
- [ ] **Phase 4: Markdown Parsing** - Markdown parsing and extraction.
- [ ] **Phase 5: Audio Transcription** - Faster Whisper local transcription.
- [ ] **Phase 6: YouTube Processing** - yt-dlp integration.
- [x] **Phase 7: Chunking Engine** - Dual-strategy chunking (Recursive + Markdown).
- [ ] **Phase 8: Embedding Engine** - BAAI/bge-small-en-v1.5 integration.
- [ ] **Phase 9: Vector Database** - ChromaDB repository implementation.
- [ ] **Phase 10: Retriever** - Semantic search and retrieval logic.
- [ ] **Phase 11: LLM Integration** - Ollama/llama.cpp local model binding.
- [ ] **Phase 12: Conversation Memory** - SQLite-backed chat history.
- [ ] **Phase 13: Prompt Engineering** - System prompts and RAG templates.
- [ ] **Phase 14: Answer Generation** - Final LangChain LCEL chains.
- [ ] **Phase 15: Source Citation** - Mapping generated answers back to metadata sources.
- [ ] **Phase 16: Frontend** - Streamlit UI development.
- [ ] **Phase 17: Testing** - Comprehensive integration and E2E tests.
- [ ] **Phase 18: Optimization** - Profiling and memory management for local execution.
- [ ] **Phase 19: Documentation** - Final review of all docs.
- [ ] **Phase 20: Final Release** - v1.0.0.
